# The official app's tray menu

- **Date:** 2026-10-30
- **Target:** Stream Deck app for Windows 7.6.0.23012 (version read from the
  running process)
- **Host:** Windows 10 Pro 22H2
- **Device:** one Stream Deck with a user-given name
- **Method:** runtime observation: a screenshot of the open tray menu taken by
  the owner. The screenshot is not stored in the repository.
- **Implemented in:** `crates/deckly/src/os/tray.rs`,
  `crates/deckly/src/runtime.rs` (`tray_devices`), `crates/deckly/src/background.rs`
- **Checked by:** tests in `crates/deckly/src/os/tray.rs` and
  `tray_lists_the_profiles_of_each_device` in `crates/deckly/src/runtime.rs`

## Observed

From top to bottom, with separators between the groups:

1. An item that opens the configuration window, named after the app.
2. The device's name, greyed out, followed by the list of profiles. One
   profile has a check mark.
3. Preferences, followed by an entry for the official marketplace.
4. An item that quits the app.

## Inferred

- The greyed-out line is a heading, not a command.
- The check mark is the profile the device shows now, and choosing another
  profile switches the device to it.
- The list holds the profiles of that device. Deckly lists the profiles made
  for the device's model, because key layouts differ between models.

## Deckly differences

- The first item reads "Configure Deckly" and the last "Quit Deckly".
- There is no marketplace entry: Deckly has no marketplace.

## Unknowns and next steps

- The layout with several devices. Deckly repeats the device group for each
  connected device.
- The menu with no device connected. Deckly leaves the device group out.
- The order of the profiles in the official list. Deckly uses its own profile
  order.
